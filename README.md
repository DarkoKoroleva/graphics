# Техническое задание на цикл лабораторных работ по компьютерной графике

**Технологический стек:** C++17, Win32 API, DirectX 11 (Direct3D 11 + DXGI), HLSL (шейдеры компилируются в рантайме через `D3DCompile`), DirectXMath.

**Общие требования ко всем работам:**
- Проект собирается в Visual Studio (файлы `.sln` / `.vcxproj`).
- Приложение создаёт окно Win32 и корректно обрабатывает изменение его размера (`WM_SIZE` → пересоздание swap chain / буфера глубины).
- Ресурсы Direct3D (буферы, шейдеры, представления) должны корректно освобождаться при закрытии приложения.
- Ошибки инициализации (компиляция шейдеров, создание устройства и т.п.) должны обрабатываться с выводом диагностического сообщения, а не приводить к падению без объяснения.
