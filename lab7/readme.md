
## Лабораторная работа №7. Инстансинг и frustum culling (CPU)

**Цель:** отрисовать множество копий объекта за один вызов отрисовки и отсечь невидимые экземпляры на CPU.

**Требования:**
1. Реализовать инстансированную отрисовку: данные каждого экземпляра (матрица модели, матрица нормалей, параметры материала, индекс текстуры) передаются в шейдер через константный/структурированный буфер, индекс экземпляра — через `SV_InstanceID`.
3. Анимировать экземпляры во времени.
4. Реализовать построение шести плоскостей пирамиды видимости (frustum) из матрицы вида-проекции.
5. Для каждого экземпляра вычислить ограничивающий объём (AABB) и на CPU проверить его пересечение с пирамидой видимости; отрисовывать (или включать в инстансированный вызов) только видимые экземпляры.
6. Сохранить из предыдущих работ буфер глубины, освещение и skybox.
7. Добавить фильтр
