## Лабораторная работа №5. Прозрачность

**Цель:** реализовать корректный рендер полупрозрачных объектов поверх непрозрачной сцены.

**Требования:**
1. Дополнить сцену из работы №4 (skybox + непрозрачные объекты) плоскими полупрозрачными объектами (минимум два).
2. Подержать буфер глубины формата D32_FLOAT.
3. Для полупрозрачных объектов отключить запись в буфер глубины.
4. Реализовать сортировку полупрозрачных объектов по расстоянию до камеры и отрисовку в порядке «от дальних к ближним».
